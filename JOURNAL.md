# Journal des choix

## 2026-11-17 – Installation de Node.js

- **Décision :** installer Node.js avec le dépôt NodeSource et apt.
- **Autres possibilités :** le paquet nodejs d'Ubuntu, le site nodejs.org.
- **Raison :** NodeSource donne la version LTS récente, et les commandes peuvent être écrites dans mon README pour être refaites à l'identique.

## 2026-11-03 – Système pour le terminal

- **Décision :** utiliser Ubuntu comme environnement Linux pour travailler dans le terminal.
- **Autres possibilités :** Windows CMD, PowerShell ou Git Bash.
- **Raison :** Ubuntu permet d'apprendre les commandes Linux et de travailler dans un environnement adapté au développement web.

## 2026-11-05 – Choix de l'éditeur de code

- **Décision :** utiliser Visual Studio Code (VS Code) comme éditeur de code.
- **Autres possibilités :** Sublime Text, Notepad++ ou Vim.
- **Raison :** VS Code est gratuit, facile à utiliser et propose des extensions utiles pour HTML, CSS, JavaScript et Git.
